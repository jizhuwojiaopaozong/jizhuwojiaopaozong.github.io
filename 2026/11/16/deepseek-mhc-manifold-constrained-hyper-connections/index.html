重构残差连接：DeepSeek mHC 的数学原理深度解读（Birkhoff 多面体与 Sinkhorn-Knopp）

发表于 2026-11-16 分类于 mHc 阅读次数：
解读 DeepSeek mHC：HC 为何破坏恒等映射、双随机矩阵流形如何恢复稳定性、Sinkhorn-Knopp 投影的工程实现，附推导与图式

核心主线：残差连接靠恒等映射保住深层网络的梯度，但单车道太窄；HC 把残差流加宽成 n 车道却因无约束混合变成信号放大器；mHC 用 Sinkhorn-Knopp 把连接矩阵投影到 Birkhoff 多面体（双随机矩阵流形），用「守恒的混合」换回稳定性。
本讲目标：读完你能回答「恒等映射为什么是深层网络的生命线、HC 怎么破坏它」「双随机矩阵的三个条件各自保住什么」「Sinkhorn-Knopp 为什么迭代 20 次就够工程使用」

1. 残差连接：恒等映射是深层网络的生命线

先把问题放回起点：深度网络每一层是一个函数

$$x_{l+1} = \mathcal{F}(x_l, W_l)$$

其中 $x_l, x_{l+1} \in \mathbb{R}^{1 \times C}$ 是第 $l$ 层的输入输出，$W_l$ 是该层参数，$\mathcal{F}$ 可以是卷积、注意力等任意映射。层一多就出事：信号每经过一次非线性映射就被折损一点，叠到几十层后浅层信息衰减殆尽，梯度往回传时更是层层相乘、要么爆炸要么消失。

ResNet 的天才之处在于给每层加了一条「什么都不做」的旁路：

$$x_{l+1} = x_l + \mathcal{F}(x_l, W_l)$$

把它从第 $i$ 层 telescoping 展开到第 $L$ 层，会得到一个极其干净的形式：

$$x_L = x_i + \sum_{l=i}^{L-1} \mathcal{F}(x_l, W_l)$$

深层状态 = 浅层状态 + 一路的修正项之和。对它求梯度，$\partial x_L / \partial x_i$ 里天然含一个单位阵 $I$（原笔记未展开，笔记补充：这正是反向传播时梯度「至少有一份原样传回」的保证，任何层的修正项梯度再小，恒等通路那一份都不会消失）。这就是恒等映射（Identity Mapping） 特性：浅层信息有一条无损高速公路直达深层。

但大模型时代这条高速公路暴露了瓶颈：只有一条车道、宽度只有 C，能携带的浅层信息有限。想加宽，就有了 Hyper-Connections。

记住这个就够了：残差连接的价值是恒等映射——梯度里永远有一份 $I$；它的代价是单车道、信息容量有限。

2. Hyper-Connections：把一条快捷通道加宽成 n 条车道

HC 的思路是把残差流从 $1 \times C$ 的向量扩展成 $n \times C$ 的矩阵（$n$ 为拓展率，即 n 路并行残差），并用三个可学习的小矩阵管理车道间的交通：

$$x_{l+1} = \mathcal{H}_l^{\mathrm{res}} x_l + (\mathcal{H}_l^{\mathrm{post}})^{\top} \mathcal{F}(\mathcal{H}_l^{\mathrm{pre}} x_l, W_l)$$

  • $\mathcal{H}_l^{\mathrm{res}} \in \mathbb{R}^{n \times n}$：残差混合矩阵，负责 n 条车道之间的横向交互与跨深度传递
  • $\mathcal{H}_l^{\mathrm{pre}} \in \mathbb{R}^{1 \times n}$：把 n 路特征聚合成 1 路送进 $\mathcal{F}$
  • $\mathcal{H}_l^{\mathrm{post}} \in \mathbb{R}^{1 \times n}$：把 $\mathcal{F}$ 的 1 路输出再广播回 n 路


graph LR
  X[xl n×C] --> R[Hres 混合]
  X --> P[Hpre 聚合]
  P --> F[Layer F]
  F --> Q[Hpost 广播]
  R --> S((相加))
  Q --> S
  S --> Y[xl+1 n×C]

精妙之处在于成本：$\mathcal{F}$（注意力/FFN）仍然只处理 $1 \times C$ 的聚合特征，计算量一分没加；新增参数只是三个小矩阵，且 $n \ll C$。等于用几乎免费的线性混合换来了更丰富的拓扑连接——原笔记的比喻是「不改变计算开销的前提下显著提升拓扑复杂性」。

记住这个就够了：HC = 把残差加宽成 n 路 + 三个小矩阵做「聚合-计算-广播」，主计算 $\mathcal{F}$ 的开销不变。

3. 无约束的代价：复合映射把高速公路变成放大器

把 HC 逐层展开，从第 $l$ 层到第 $L$ 层的信号传递是：

$$x_L = \left( \prod_{i=1}^{L-l} \mathcal{H}_{L-i}^{\mathrm{res}} \right) x_l + \sum_{i=l}^{L-1} \left( \prod_{j=1}^{L-1-i} \mathcal{H}_{L-j}^{\mathrm{res}} \right) (\mathcal{H}_i^{\mathrm{post}})^{\top} \mathcal{F}(\mathcal{H}_i^{\mathrm{pre}} x_l, W_l)$$

对比第 1 节的 telescoping 形式会发现：残差通路前面的系数从单位阵 $I$ 变成了一串矩阵的连乘 $\prod \mathcal{H}^{\mathrm{res}}$。**恒等映射还在不在，全看这个连乘是否接近 $I$**——而 $\mathcal{H}^{\mathrm{res}}$ 是无约束的可学习矩阵，没有任何力量保证它「不放大不缩小」。

把每层放大倍数想成一个略大于 1 的数 $\lambda$：单层无所谓，$L$ 层复合就是 $\lambda^L$ 的指数效应。论文用 Amax Gain Magnitude 度量这种偏离：取复合映射行和的最大绝对值刻画前向最坏扩张、列和的最大绝对值刻画反向传播——HC 里该指标能飙到 3000，意味着信号从第一层走到最后一层被放大三千倍；训练曲线上 HC 在约 12k 步处损失激增、梯度范数剧烈震荡，正是复合映射失控的指纹。

第二个代价是内存带宽。加宽残差流后，每个 token 的读写量从残差连接的 $2C$/$C$ 涨到：

$$\text{Read} = (5n+1)C + n^2 + 2n, \qquad \text{Write} = (3n+1)C + n^2 + 2n$$

近似与 $n$ 成正比；再加上反向传播要保存 $\mathcal{H}^{\mathrm{pre}}$、$\mathcal{H}^{\mathrm{post}}$、$\mathcal{H}^{\mathrm{res}}$ 相关的中间激活，I/O 成为吞吐量的新瓶颈。

记住这个就够了：HC 的病根是 $\prod \mathcal{H}^{\mathrm{res}}$ 不受约束——单层偏差无害，L 层连乘指数放大，前向爆炸、反向消失，还附带 $O(nC)$ 级内存开销。

4. mHC 的解法：把连接矩阵投影到 Birkhoff 多面体

mHC（Manifold-Constrained HC）的直觉一句话：既然无约束的 $\mathcal{H}^{\mathrm{res}}$ 像混乱的水流，就把它限制在一条规则的「河道」里——这条河道是双随机矩阵流形，即 Birkhoff 多面体 $\mathcal{M}^{\mathrm{res}}$。投影后的连接矩阵必须同时满足三个条件：

$$\mathcal{P}_{\mathcal{M}^{\mathrm{res}}}(\mathcal{H}_l^{\mathrm{res}}) := \left\lbrace \mathcal{H}_l^{\mathrm{res}} \in \mathbb{R}^{n \times n} \quad\middle|\quad \mathcal{H}_l^{\mathrm{res}} \mathbf{1}_n = \mathbf{1}_n,\quad \mathbf{1}_n^{\top} \mathcal{H}_l^{\mathrm{res}} = \mathbf{1}_n^{\top},\quad \mathcal{H}_l^{\mathrm{res}} \geq 0 \right\rbrace$$

即行和为 1、列和为 1、元素非负（$\mathbf{1}_n$ 是全 1 向量）。注意 $n=1$ 时这个集合退化成标量 1——正好回到 ResNet 的恒等映射，说明 mHC 是残差连接在 $n$ 路情形下的「守恒推广」。

为什么双随机矩阵能治病？三层保证，一层比一层深：

  • 非扩张：双随机矩阵的谱范数 $|\mathcal{H}^{\mathrm{res}}|_2 \leq 1$，信号经过它不会被放大，梯度爆炸的源头被掐掉
  • 组合封闭：双随机矩阵相乘仍是双随机矩阵——所以不管叠多少层，复合映射 $\prod \mathcal{H}^{\mathrm{res}}$ 永远留在流形上，深度增加不会累积出不稳定（原笔记未展开，笔记补充：这正好补上第 3 节 $\lambda^L$ 指数放大漏洞的盖子，因为此时 $\lambda \leq 1$）
  • 几何含义：Birkhoff-von Neumann 定理说该多面体是全体排列矩阵的凸包，$\mathcal{H}^{\mathrm{res}} = \sum_k \theta_k P_k$（$\theta$ 在单纯形上）。也就是说双随机混合等价于「对若干种车道重排方案做加权平均」——信息只是被重新分配，总量守恒，既不凭空产生也不无故消失

同时，流形约束并不禁止 n 条残差流之间的相互作用（混合权重照样学），表达能力保留；被牺牲的只有「放大/缩小总量」这种危险自由度。对 $\mathcal{H}^{\mathrm{pre}}$、$\mathcal{H}^{\mathrm{post}}$ 则施加较弱的非负约束：$\mathcal{H}^{\mathrm{pre}} = \sigma(\tilde{\mathcal{H}}^{\mathrm{pre}})$、$\mathcal{H}^{\mathrm{post}} = 2\sigma(\tilde{\mathcal{H}}^{\mathrm{post}})$，用 sigmoid 挡掉正负系数相互抵消造成的信号对消（原笔记未展开，笔记补充：post 用 $2\sigma$ 而非 $\sigma$，把取值中心从 0.5 抬到 1，避免广播路径系统性地减半信号）。

记住这个就够了：mHC 把 $\mathcal{H}^{\mathrm{res}}$ 投影到双随机矩阵流形——行和、列和为 1 加非负，换来非扩张、组合封闭、守恒混合三条稳定性保证，且 $n=1$ 时退回 ResNet。

5. Sinkhorn-Knopp：20 次迭代逼近双随机流形

约束定义好了，剩下的问题是：怎么让可学习的 $\mathcal{H}^{\mathrm{res}}$ 每次前向都落在流形上？答案是经典的 Sinkhorn-Knopp 迭代。先给出映射矩阵的参数化——给定第 $l$ 层输入 $x \in \mathbb{R}^{n \times C}$，展平为 $\vec{x}_l \in \mathbb{R}^{1 \times nC}$，动态部分由输入决定、静态部分是可学习偏置：

$$\begin{cases} \vec{x}’_l = \mathrm{RMSNorm}(\vec{x}_l) \ \tilde{\mathcal{H}}_l^{\mathrm{pre}} = \alpha_l^{\mathrm{pre}} (\vec{x}’_l \varphi_l^{\mathrm{pre}}) + b_l^{\mathrm{pre}} \ \tilde{\mathcal{H}}_l^{\mathrm{post}} = \alpha_l^{\mathrm{post}} (\vec{x}’_l \varphi_l^{\mathrm{post}}) + b_l^{\mathrm{post}} \ \tilde{\mathcal{H}}_l^{\mathrm{res}} = \alpha_l^{\mathrm{res}} \mathrm{mat}(\vec{x}’_l \varphi_l^{\mathrm{res}}) + b_l^{\mathrm{res}} \end{cases}$$

其中 $\varphi_l^{\mathrm{res}} \in \mathbb{R}^{nC \times n^2}$、$\varphi_l^{\mathrm{pre}}, \varphi_l^{\mathrm{post}} \in \mathbb{R}^{1 \times nC}$ 是动态线性映射，$b$ 系列是静态偏置，$\mathrm{mat}(\cdot)$ 把 $1 \times n^2$ 重排成 $n \times n$。然后分头施加约束：

$$\mathcal{H}_l^{\mathrm{pre}} = \sigma(\tilde{\mathcal{H}}_l^{\mathrm{pre}}), \quad \mathcal{H}_l^{\mathrm{post}} = 2\sigma(\tilde{\mathcal{H}}_l^{\mathrm{post}}), \quad \mathcal{H}_l^{\mathrm{res}} = \mathrm{Sinkhorn\text{-}Knopp}(\tilde{\mathcal{H}}_l^{\mathrm{res}})$$

Sinkhorn 算子分两步走：先取 $\mathbf{M}^{0} = \exp(\tilde{\mathcal{H}}_l^{\mathrm{res}})$ 把任意实矩阵变成正矩阵（顺带保证非负），再交替做列归一化和行归一化：

$$\mathbf{M}^{(t)} = \mathcal{T}_r \left( \mathcal{T}_c (\mathbf{M}^{(t-1)}) \right)$$

  B --> C[Tc 列归一]
  C --> D[Tr 行归一]
  D -->|重复 20 次| C
  D --> E[投影结果 近似双随机]

理论上正矩阵经无穷次交替归一化收敛到双随机矩阵；工程上只迭代 20 次——不保证完美落在流形上，但足够接近（原笔记的热力图里 mHC 的列和已在 1.00 附近小幅浮动）。对比热力图非常直观：HC 的 $\mathcal{H}^{\mathrm{res}}$ 元素是 ±几十甚至 ±几百的狂野数值，复合后更失控；mHC 投影后的元素全部落在 $[0,1]$、行列和贴近 1，60 层复合后依然平稳。

内存开销则靠三件工程武器压回去：Kernel Fusion 把整段 Sinkhorn 迭代合并进一个 kernel、只做一次 HBM 读写；梯度检查点在反向时重算激活、削掉内存峰值；DualPipe 通信调度解耦计算与通信依赖、掩盖多残差流的额外通信。三管齐下，4 路残差流下 mHC 相对 HC 只增加 6.7% 训练时间。

记住这个就够了：exp 保证非负、交替行列归一逼近双随机、20 次迭代够用；Kernel Fusion + 检查点 + DualPipe 把代价压到 6.7%。

6. 实验：1.6 倍放大、6.7% 开销与全面超越 HC

稳定性上，HC 的复合映射能把信号放大到 3000 倍，mHC 最高只有 1.6 倍——几乎是「原样传递」，恒等映射属性基本保住；训练曲线上 mHC 的最终损失比 HC 低 0.021，梯度范数平滑下行，没有 HC 那种 12k 步后的激增与震荡。

mHC 在多数 benchmark 上比 HC 更优，逻辑也自洽：HC 的残差流时常梯度消失或爆炸，等于加宽的车道经常塌方；mHC 保证车道守恒畅通，拓宽带来的表达收益才真正兑现。MATH 上 HC 略高（26.4 vs 26.0）说明约束并非免费午餐——个别任务上自由混合仍有一点余地，但换来的是整体可训练性。

记住这个就够了：3000 倍放大压到 1.6 倍、损失再降 0.021、benchmark 全面压过 HC，代价仅 6.7% 训练时间——稳定性是表达力的前提。

7. 串联阅读：mHC 与 Engram 是同一盘棋的两步

把这篇和本博客 N-gram 分类下的 Engram 笔记放在一起看，脉络非常清楚：mHC 把残差流扩展成多条并行分支（Engram 论文里用的就是 4 路），解决的是信息通路的宽度与稳定性；Engram 往这些分支上挂条件记忆表，解决的是知识存储的效率。Engram 的分支间参数共享策略（共享稀疏嵌入表与值投影 $W_V$、各分支独立键投影 $W_K^{(m)}$）正是架在 mHC 的多分支残差骨架之上——先有守恒的多车道高速公路，再在路边建 O(1) 的知识服务站。

两者还共享同一种方法论：给自由参数套一个结构性约束，把「学什么」的自由度和「怎么才稳定」的底线分开管理——Engram 用哈希与门控约束检索，mHC 用双随机流形约束混合。DeepSeek 的稀疏化叙事由此凑齐三块：MoE 的计算稀疏、Engram 的存储稀疏、mHC 的通路稳定。

记住这个就够了：mHC 稳住多分支残差骨架，Engram 在骨架上挂条件记忆；约束换稳定、稳定换规模，是同一套方法论。

本讲小结

机制/概念 解决什么问题 一句话
残差连接 深层信号与梯度衰减 加一条恒等旁路，梯度里永远有一份单位阵
Hyper-Connections 单车道残差信息容量有限 n 路残差 + 三个小矩阵混合，主计算开销不变
Birkhoff 多面体约束 无约束连乘指数放大信号 行和列和为 1 且非负：非扩张、组合封闭、守恒混合
Sinkhorn-Knopp 如何让可学习矩阵落在流形上 exp 转正 + 交替行列归一，20 次迭代足够工程使用
系统优化 宽残差流的 I/O 与内存峰值 Kernel Fusion + 梯度检查点 + DualPipe，开销 6.7%

学完能说的 3 句话：

  1. 残差连接的本质是恒等映射，HC 加宽残差流的同时用无约束连乘 $\prod \mathcal{H}^{\mathrm{res}}$ 破坏了它，信号可被放大数千倍。
  2. mHC 把 $\mathcal{H}^{\mathrm{res}}$ 投影到双随机矩阵流形：谱范数不超 1、连乘封闭、混合守恒，从原理上恢复稳定性。
  3. Sinkhorn-Knopp 用 exp 加 20 次交替归一实现投影，配合 Kernel Fusion 等工程手段，总代价仅 6.7% 训练时间。

概念卡片

恒等映射

  • 定义：残差通路使深层状态等于浅层状态加修正项之和、梯度中含单位阵的无损传递特性

自测题（面试速答）

  1. 无约束的 HC 为什么会破坏训练稳定性，而 mHC 为什么不会？（对应：恒等映射）

答案： 因为残差通路的系数从单位阵变成了一串无约束矩阵的连乘 $\prod \mathcal{H}^{\mathrm{res}}$，恒等映射不再成立。单层偏差看似无害，但每层放大系数略大于 1 时 L 层复合就是指数放大，HC 实测复合增益飙到 3000，前向信号爆炸、反向梯度消失，训练在 12k 步附近损失激增。mHC 把每层 $\mathcal{H}^{\mathrm{res}}$ 约束为双随机矩阵：谱范数不超过 1 故非扩张，且双随机矩阵连乘仍双随机，任意深度的复合映射都留在流形内，实测最大放大仅 1.6 倍。

  1. Birkhoff 多面体对连接矩阵施加了哪三个条件，各自保证什么？（对应：双随机矩阵）

答案： 三个条件是行和为 1、列和为 1、元素非负。行和与列和为 1 保证映射不放大也不收缩信号总量（谱范数 $\leq 1$，非扩张），非负则排除正负系数对消与符号翻转带来的振荡；三者合起来还带来组合封闭性——双随机矩阵相乘仍双随机，所以多层复合不会随深度累积失稳。几何上该集合是排列矩阵的凸包（Birkhoff-von Neumann 定理），即对车道重排方案做加权平均，信息守恒地混合；当 $n=1$ 时它退化为标量 1，正好回到 ResNet 的恒等映射。

  1. Sinkhorn-Knopp 只迭代 20 次为什么在工程上可接受？它牺牲了什么？（对应：Sinkhorn-Knopp 投影）

答案： 因为正矩阵交替行列归一化收敛到双随机矩阵，20 次后已足够接近：热图里投影后矩阵元素落在 $[0,1]$、行列和在 1.00 附近小幅浮动，复合 60 层依然平稳，稳定性收益几乎拿满。牺牲的是「精确落在流形上」——列和可能略偏离 1，属于可控的近似误差；换来的是迭代成本可控，再配合 Kernel Fusion 把整段迭代压成一次 HBM 读写、梯度检查点削峰值、DualPipe 掩通信，4 路残差流下总额外开销仅 6.7% 训练时间。
