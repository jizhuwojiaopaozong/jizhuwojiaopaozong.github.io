注意力残差：Kimi 把注意力旋转 90 度（Attention Residuals 解读）

发表于 2026-11-18 分类于 attnres 阅读次数：
解读 Kimi《注意力残差》：层间注意力替代无差别累加、PreNorm 稀释、full 与 block-wise 两形态、与 HC/mHC 的统一框架对照

核心主线：Kimi 的《注意力残差》把注意力机制「旋转 90 度」——从 token 之间的横向注意力变成层与层之间的纵向注意力，用加权聚合替代残差流的无差别累加，同时治愈不对称性与 PreNorm 稀释。
本讲目标：读完你能回答「注意力旋转 90 度到底旋转的是什么」「传统残差的两大毛病各自是什么」「full 与 block-wise 两种注意力残差如何权衡、与 HC/mHC 有何异同」

1. 开场：Kimi 的技术报告与「旋转 90 度」的比喻

Kimi 团队发布了名为《注意力残差》（Attention Residuals）的技术报告，发布后马斯克也关注到并评价这是来自 Kimi 的 impressive work。视频要回答的问题是：这项工作究竟巧妙在哪里？

论文作者之一给了一个极具画面感的描述：注意力残差把注意力机制顺时针旋转了 90 度。现在的注意力机制是横向的——关注不同 token 之间的关系；旋转 90 度之后，注意力发生在层与层之间，也就是模型的深度维度上。整期视频沿四条线展开：传统残差连接及其问题、注意力残差的两种形态（full 与 block-wise）、与字节 Hyper-Connections（HC）和 DeepSeek mHC 的异同、以及论文给出的统一框架。

记住这个就够了：一句话记住这篇报告——把 token 间的横向注意力旋转 90 度，变成层间的纵向注意力。

2. 传统残差连接与递归展开

传统残差连接由何恺明提出，已应用很久且在当前主流大模型上广泛使用。记 $h_l$ 为进入第 $l$ 层的 hidden state、$F_l$ 为该层变换，标准残差的意思是：$h_l$ 经过 $F_l$ 之后的量还要与未经变换的 $h_l$ 相加——直接把上一层的输出加进来成为本层输出：

$$h_{l+1} = h_l + F_l(h_l)$$

做一个递归的展开可以发现，第 $L$ 层（后面任意某层）都可以写成前面某一层加上各层增量累加的形式：把每层的增量记为 $v_j$，则 $h_L = h_0 + \sum_{j} v_j$——过往所有层输出的累加和。

残差连接最大的好处是方便梯度回传：可以把它理解为一条直通的高速公路，求梯度时会翻出一个单位阵 $I$，即恒等映射（identity mapping）——不管其他项多么复杂，有这样一条直通连过来的线，梯度就能直接回传到前面。

记住这个就够了：传统残差 = 逐层累加所有增量；梯度里永远有一份恒等映射，这是它能撑住深度的原因。

3. 两大毛病：无差别相加与 PreNorm 稀释

第一个问题是无差别的相加，这与当前主流模型的其他部分很不对称：序列维度上，Attention 对多个 token 不是无差别相加，而是通过 softmax 机制计算注意力分数、决定模型更关注哪些 token 的加权聚合；专家维度上，MoE（混合专家模型）通过 router（路由器）动态决定每次使用哪些专家。唯独在模型深度这一维度上，残差连接还在用一种固定的加法，和其他部分感觉很不匹配。

第二个问题叫 PreNorm dilution（预归一化稀释）：每一次往前传的过程中，每一层的残差流都会加入一个增量；而由于有了 Norm（归一化），各层增量的大小其实是相近的——这样每层的相对贡献就越来越小。比如到了第 30 层想找回第 1 层的信息，会发现它的占比已经非常非常小；长距离依赖的信息因此很难被记住、很难被找出。

注意这两个毛病的方向相反：一个是「该加权的地方没加权」，一个是「早期层的信号被后期增量淹没」。注意力残差对两者同时下手。

记住这个就够了：深度维度的固定加法与序列/专家维度的动态选择不对称；PreNorm 稀释让早期层贡献随深度衰减——这是注意力残差要治的两个病。

4. 注意力残差：把注意力旋转 90 度

怎么理解「旋转 90 度」：现在的注意力关注不同 token 之间，是横向的；旋转 90 度就是在层与层之间做注意力——不再把每层增量固定无差别地加在一起，而是在加之前先做加权求和：对每个层计算一个注意力分数，让每一层自己决定更应该关注之前的哪一层。于是递归展开从累加变成加权：

$$h_L = \sum_{j} \alpha_{lj} v_j, \qquad \alpha_{lj} = \mathrm{softmax}_j \left( \omega_l^{\top} \mathrm{RMSNorm}(v_j) \right)$$

其中 $\omega_l$ 是每一层的偏好向量，决定它想从历史层里找到哪些信息；关键性质是 $\omega_l$ 不是输入依赖的——它不看当前 token，只与层有关；而 $v_j$ 与输入相关，不同 token、不同上下文下都不一样。两者加 RMSNorm 后计算注意力分数再加权。这就是 full attention residuals（完全的注意力残差）。

那能不能让 $\omega_l$ 输入依赖？可以：用当前隐藏状态 $h_l$ 经一个可学习矩阵变换生成 query。效果确实有微小提升，但代价是多一次矩阵变换、更贵，而且推理上会变成串行的——所以默认不用。这个取舍值得记住：把「层偏好」做成静态参数，换来了并行与便宜。

记住这个就够了：层间注意力 = 每层一个静态偏好向量对历史层增量打分加权；输入依赖版更准但更贵更串行，故默认不用。

5. 同构类比：RNN 到 Attention 的改进重演一遍

论文还提供了另一个理解角度：模型的深度实际上就是另外一种时间，并把 RNN 放在一起阐述——两个改进是完全相通的。

RNN 到第 $t$ 个时间步只能拿到上一个压缩状态 $s_{t-1}$：前面所有时间步的信息都被压缩进这一个状态里，问题是长距离依赖的信息难记、信息被压缩稀释了。怎么解决？注意力机制（Attention Is All You Need）：不再只依赖这个「压缩包」，而是直接看之前的所有 token，对它们计算注意力分数。

把镜头切回残差连接：传统残差的递归累加正是这样一种「压缩」——把之前所有层都压进一条残差流里；注意力残差不再压缩，而是直接把之前的每个层拿出来计算注意力分数。于是层数 $L$ 就像时间步 $T$：Attention 是对 RNN 做了 token/时间步上的注意力，注意力残差就是对残差连接做了层数上的注意力——打分、加权聚合，不再每次压缩到一起。

记住这个就够了：残差流之于深度，等价于压缩状态之于时间；注意力残差 = 在深度轴上重演一遍 RNN→Attention 的革命。

6. 统一框架：区别仅在 M

注意力残差论文里提出了一种大一统的架构：所有和残差相关的改进都被定义进同一个框架，彼此的区别仅仅是 $M$ 的不同。

  • 传统残差连接：$M$ 等于单位阵——$v_0$ 加 $v_1$ 一直加到 $v_{L-1}$，直接相加
  • HC 与 mHC：做的是一种压缩/变换——在每个残差流与残差流之间的线性变换（流与流之间的混合）
  • 注意力残差：直接把每一层拿出来做加权，对所有历史层用一个注意力机制

这个视角的价值在于把散落的改进排成了一条谱系：改 $M$ 就是改「历史信息以何种方式汇入当前层」——恒等累加、流间变换、层间注意力是三个由简到繁的答案。

记住这个就够了：统一框架里残差改进的差异全在 $M$：单位阵累加 / 流间变换 / 层间注意力加权。

7. Block-wise 版：用块数换复杂度

除了 full 形态，还有 block-wise（块级）的注意力残差：把总共 $L$ 层分为 $N$ 个块，每个块内部先用普通的加法做递归累加；块内仍然是递归的累加，但块与块之间做注意力检索。

收益是工程性的：不管存储还是通信的复杂度，都从本来线性级别的 $O(L)$ 降低到块个数 $O(N)$。实验表明 $N=8$ 的时候就已经接近 full attention residuals 的收益了——所以 block-wise 可以在低成本的情况下拿到大部分收益。这是一个典型的「精度换复杂度」旋钮：块内免费累加、块间才付注意力的钱。

记住这个就够了：块内递归累加、块间注意力检索，复杂度 $O(L) \to O(N)$；$N=8$ 已接近 full 的收益。

8. 与 HC/mHC 对照与收尾

把三家放在一起看：HC 和 mHC 在某种意义上把残差流做复杂了——多路残差流、混合矩阵、流形约束；残差流很复杂，可能就违背了原本的初衷（那条恒等映射的高速公路）。而 Attention Residuals 走的是另一条路：不增加残差流的路数，而是把模型的深度这个维度也变成一个 Attention 的轴，让单条残差流里的历史信息按注意力加权汇入。

视频最后过了三张结构图：传统残差连接（逐层直加）、full attention residuals（每层对全部历史层加权）、block-wise（一块一块，第 $N-1$ 块、第 $N-2$ 块之间做注意力）。结合本博客 mHc 分类下的两篇 mHC 解读正好凑成一张拼图：mHC 用双随机约束稳住多路混合，注意力残差用层间注意力替换无差别累加——两者都在回答同一个问题：残差这条高速公路，怎样才能又宽又稳还不堵车。

记住这个就够了：HC/mHC 加宽并约束残差流，注意力残差给深度轴装注意力；三条路线共用一个统一框架，区别仅在 $M$。

本讲小结

机制/概念 解决什么问题 一句话
层间注意力加权 深度维度固定加法与序列/专家维度不对称 每层用偏好向量对历史层增量打分加权
静态偏好向量 输入依赖 query 更贵更串行 ω 只与层有关，v 与输入有关，默认不输入依赖
Block-wise 分块 full 形态存储/通信 O(L) 太贵 块内累加块间注意力，O(N) 且 N=8 接近 full
统一框架 M 残差改进各自为政 恒等累加/流间变换/层间注意力只是 M 的不同

学完能说的 3 句话：

  1. 注意力残差 = 把注意力从 token 轴旋转 90 度到深度轴，用层间加权聚合替代无差别累加。
  2. 它同时治两个病：深度维度的固定加法不对称，以及 PreNorm 稀释让早期层贡献衰减。
  3. block-wise 用块内累加+块间注意力把复杂度降到 O(N)，N=8 即接近 full 收益；与 HC/mHC 的区别在统一框架里只是 M 的不同。

自测题（面试速答）

  1. 「把注意力机制旋转 90 度」具体指什么？作用在哪个维度上？（对应：注意力残差）

答案： 指注意力的作用对象从序列维度换成深度维度：原来的注意力横向地发生在 token 之间，旋转 90 度后发生在层与层之间——每一层不再把历史层增量无差别累加，而是先对每个历史层计算注意力分数再加权求和。公式上递归展开从 $h_L = h_0 + \sum v_j$ 变成 $h_L = \sum \alpha_{lj} v_j$，分数由该层静态偏好向量 $\omega_l$ 与输入相关的 $v_j$ 经 RMSNorm 后算得。所以旋转的不是网络结构图，而是「注意力打分发生在哪个轴上」。

  1. PreNorm 稀释是什么？为什么它让长距离依赖难记？（对应：PreNorm 稀释）

答案： 它指每层往残差流加入的增量因归一化而大小相近，导致早期层的相对贡献随深度不断变小。比如到第 30 层时第 1 层的占比已经微乎其微，想找回早期信息就像在恒量注入的河流里捞第一滴墨水——长距离依赖因此难记、难取。这与 RNN 把全部历史压进一个状态被稀释是同构的问题；注意力残差的解法是不再压缩累加，而是让每层可以直接对早期层打高分重新取回。

  1. Block-wise 注意力残差如何降低复杂度？N=8 的实验说明了什么？（对应：块级注意力残差）

答案： 它把 L 层分成 N 个块：块内仍用普通加法递归累加（免费），只在块与块之间做注意力检索，于是存储与通信复杂度从线性的 $O(L)$ 降到块数个数的 $O(N)$。实验表明 N=8 时收益已接近 full attention residuals，说明层间注意力的收益主要由「粗粒度的跨块检索」贡献，细到每层全连接式的加权并非必需——这是用少量精度换大幅工程成本的典型旋钮。

  1. 注意力残差为什么默认用静态偏好向量，而不是输入依赖的 query？（对应：注意力残差）

答案： 因为输入依赖版本虽然效果有微小提升，但需要用当前隐藏状态经一个额外可学习矩阵变换来生成 query，既更贵又让推理变成串行——本层的层间权重必须等当前状态算完才能产生，破坏了并行性。默认设计让偏好向量 ω 只与层有关、与 token 无关，而把输入相关性交给 v_j 一侧（不同 token 的历史增量本就不同），于是打分所需的静态部分可以预计算、并行执行。这是一个「微小精度换并行与便宜」的 deliberate 取舍，论文实验也确认提升幅度不值得代价。

  1. 传统残差的递归展开里，恒等映射出现在哪里？注意力残差替换累加后靠什么保住梯度通路？（对应：恒等映射）

答案： 恒等映射出现在递归展开的结构里：第 L 层等于浅层状态加上各层增量之和，求梯度时翻出单位阵 I，形成直通高速公路。注意力残差把无差别累加换成加权和后，直通项不再天然存在，风险是梯度通路被权重调制；论文的统一框架正是为此把各种改进定义在同一架构内对比 M 的选择，而 block-wise 版块内仍保留递归累加，等于在块内保留了恒等高速公路、只在块间做注意力——可以理解为把恒等映射从「全程直通」收缩为「块内直通」。这也是它与 HC/mHC 共享的设计直觉：任何混合都不能彻底切断梯度直通。
